# corso.racing

Static site for Corso Racing, a family race team from Charlotte, North Carolina: Nicholas Corso #11 and Luca Corso #57 in karts and non-wing outlaw micro sprints.

One scroll-scrubbed page in ten reels (`index.html`, `css/style.css`, `js/app.js`), served by GitHub Pages at https://corso.racing. No build step; edit and push.

- `?at=<reel>,<progress>` jumps to a point in the film for review (for example `?at=season,0.5`).
- Team inbox: set `CONTACT_EMAIL` at the top of `js/app.js` once it exists.
- The page carries `noindex` until the Corso family signs off; flip the robots meta in `index.html` to publish to search engines.
- Team photos are real. Concept liveries and track scenes are illustrations.

Built by Fortuity.
